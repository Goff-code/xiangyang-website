# 向阳前行官网

面向创业者与准备创业者的单页官网，展示会员、活动、会员权益与微信咨询入口。基于创始人提供的 PPT 和已确认的需求制作。

本仓库公开用于项目审阅与协作，任何人可以读取源码及提交历史；仓库未附加开源许可证。图片与人物资料的使用范围以已有授权为准。

当前尚未启用 GitHub Pages。仓库网址用于查看文件与交给 Agent 审阅，页面效果可按下面的方法在本地打开。

## 文件结构

- `public/index.html`：页面文案、会员计划、活动与联系方式。
- `public/styles.css`：颜色、排版和手机适配。
- `public/app.js`：会员浏览、微信复制、二维码弹窗与咨询提示。
- `public/assets/`：经授权公开的照片与微信二维码。
- `CONTENT_SOURCES.md`：素材来源及内容边界，随仓库公开供审阅。
- `.github/previews/`：当前版本的实际页面截图，供直接查看设计。
- `.github/workflows/pages.yml`：手动发布 GitHub Pages 的工作流，仅上传 `public/`。
- `DEPLOYMENT.md`：当前部署状态与后续操作说明。

## 本地查看

首次获取项目：

```sh
git clone https://github.com/Goff-code/xiangyang-website.git
cd xiangyang-website
```

在仓库目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory public
```

然后在浏览器访问 `http://127.0.0.1:8765/`。预览服务运行期间仅这台电脑可访问；结束预览时在终端按 `Ctrl+C`。

项目是纯静态 HTML、CSS 和 JavaScript，不需要安装 npm 依赖、登录 GitHub 或提供 API 密钥。也可直接用浏览器打开 `public/index.html`；HTTP 预览更接近正式网页的行为。

## 给协作 Agent 的审阅说明

先读取本文件及 `CONTENT_SOURCES.md`，再查看 `public/` 中的页面代码。具备终端与浏览器能力的 Agent 可以按上述步骤启动本地预览，检查电脑和手机布局；只能读取仓库的 Agent 可以审阅文案与代码，但不能据此宣称已看过实际渲染效果。

当前重点是确认整体风格、会员介绍、活动内容、会员权益及微信咨询流程。会员学习与收获案例尚待补充，不要虚构客户反馈、合作结果或收益。原始 PPT 不在仓库中，需要核对原文时应向项目负责人索取。除非项目负责人另行要求，审阅阶段无需修改文件、提交代码或发布网站。

## 上传边界

仓库只保存网站文件、维护说明与部署工作流。不会导入原 PPT、临时文件、旧托管平台配置、旧 Git 历史或账户登录凭据。提交使用 GitHub 隐私邮箱。

本网站无后端、数据库或外部 API，不需要配置密码或 API 密钥。GitHub Actions 使用平台临时授权，不在源文件中保存令牌。不要将 `.env`、密码、私钥或访问令牌写入 `public/`，也不要使用 `git add -f` 绕过忽略规则。
